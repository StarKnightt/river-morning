# Credits - River Morning conifers (public/assets/trees)

## Textures (all files in textures/)
Derived from Poly Haven "Fir Tree 01" and "Pine Tree 01" by Rob Tuytel (photography) and Rico Cilliers (modelling),
CC0 1.0 (public domain dedication): https://polyhaven.com/a/fir_tree_01, https://polyhaven.com/a/pine_tree_01,
license https://polyhaven.com/license. Twig sprigs cropped into a needle-card atlas; barks re-encoded as WebP.

## Tree geometry
Branch skeletons grown with ez-tree by Daniel Greenheck (https://github.com/dgreenheck/ez-tree, commit
dcf309b), MIT License. Crown shaping, meshing, UVs and GLB export written for River Morning.
ez-tree's own bark/leaf textures are not used. The young trees (spruce_y, fir_y, spruce_t) and the snags (snag_a,
snag_b) were added later with the same generator, which also marks dead branch wood in COLOR_0.a.
